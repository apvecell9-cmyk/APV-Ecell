# APV E-Cell

https://ecellapv.in/

The official website for APV E-Cell — the entrepreneurship cell fostering innovation, startup culture, and entrepreneurial leadership among students.

## Tech Stack

- React + TypeScript
- TanStack Router + Start
- Tailwind CSS v4
- Framer Motion
- Nitro (Cloudflare)

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
